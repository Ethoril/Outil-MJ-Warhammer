Les recherches ciblées sur le domaine éditeur, le titre et le nom canonique n'ont pas fourni de correction officielle dans les résultats effectivement examinés. Cela signifie recherche incomplète sans correction obtenue, pas preuve qu'aucun erratum n'existe. Les copies non officielles remontées par le moteur n'ont pas été utilisées comme autorité.
