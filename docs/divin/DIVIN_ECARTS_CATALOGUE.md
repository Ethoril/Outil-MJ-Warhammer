# Écarts du catalogue local — miracles de Myrmidia

> **Correction documentaire du 17 octobre 2026 : les neuf sources ont été retrouvées dans Up in Arms p.79.** Elles demandent une adaptation V4/V5; les contrats restent bloqués, avec leur ancien motif dans le registre. Voir [le complément de sources](DIVIN_COMPLEMENT_SOURCES.md). Les nombres de tests ci-dessous décrivent la recette du code inchangé.

Le catalogue et son snapshot restent inchangés. Pour cette comparaison, le livre de base V5 anglais fait autorité; les six lignes locales concordent avec des données V4, ce qui n’établit pas leur conformité V5. Les six descriptions V5 ont été contrôlées sur la page imprimée 224.

Le détail des correspondances et ambiguïtés est dans `DIVIN_COMPLEMENT_SOURCES.md`, puis le programme exhaustif dans `DIVIN_PLAN_EXHAUSTIF.md`.

La publication de toute correction au CSV ou au snapshot est différée. Ce rapport propose des deltas pour arbitrage ultérieur; il ne modifie ni la source publique ni les fichiers de catalogue. La convention validée est de conserver les mêmes valeurs numériques et de les afficher en mètres de jeu, en gardant l’unité source dans la provenance. Les corrections du catalogue local et exports sont prévues; aucune écriture publique n’est autorisée.
